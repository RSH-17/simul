# Mixed v1.5.3과 v1.6.0의 벽·장애물 관찰 비교

각 장면의 기준판과 후보판이 같은 Gazebo 월드 파일, 출발 위치·헤딩, 480×480 5 FPS 영상과 180초 시뮬레이션 시간 한도를 사용한다. 각 장면은 사전 고정한 한 쌍의 개발 시험이다. 로봇은 정답 마커와 정답 장애물 정보를 받지 않는다. 현재 후보의 구조와 원래 실행 경로는 [정책 설명](../../policy_candidates/2026-11-21_global_face_v160/README.md)에 정리했다.

| 장면 | 배치 |
|---|---|
| A | 벽 세 곳에만 마커를 부착한 공간 |
| B | 상자 세 개에만 마커를 한 개씩 부착한 공간 |
| C | 벽 하나와 서로 다른 두 상자에 마커가 있는 공간 |
| D | 출발 시 상자에 가려지고 우회로가 있는 후면. 교착 상태의 재개는 통제된 costmap 변경 테스트로도 확인한다. |
| E | 출발 위치에서 상자 셋이 서로 가려지는 배치 |
| F | 상자의 남면과 벽 사이 간격이 0.48m인 좁은 통로 |

## 측정

- 임무에 등록된 정확한 ArUco ID와 독립 평가기의 등록 후 1.5m 이내 접근 증거를 따로 센다. 엄격 성공은 세 ID, 세 근거리 RGB 확인과 독립 거리, 지도 오차 25cm 이하, 범퍼 0회를 모두 요구한다.
- 벽과 각 상자의 실제 둘레를 간격 10cm 이하로 나누고 부착 높이 45cm에서 평가한다. 실제 처리된 영상 시각에 Gazebo 정답 자세를 보간하여 실측 광학 TF와 카메라 행렬로 투영한다. 가려지지 않고 거리·입사각·판독 픽셀 사전조건이 맞는 0.15초 이상 간격의 영상 3개가 필요하다. 관찰 비율은 표본의 물리적 길이로 가중하며 면의 70% 이상을 확인했을 때 해당 면을 완료로 친다. 실제 픽셀에서 마커가 판독됐는지는 별도 ID 지표로 측정한다. 가림 검사는 이 시험의 직립 상자와 지정 높이를 대상으로 한다.
- Nav2 목표의 고유 UUID별 중단·취소·성공을 분리한다. 중복 도달은 활성 목표 구간에서 정답 궤적이 30cm 안에 접근한 뒤 이미 도달한 목표의 35cm 이내에 다시 도달한 횟수다. 정지 관찰 목표도 이 정의에 들어간다. 경로와 시간은 미완주도 포함한다.
- 독립 평가의 미관찰 사유와 정책이 기록한 물체별 PENDING, OBSERVED, BLOCKED, FAILED를 구분한다. 궤적과 실제 촬영 시각으로 확인할 수 없는 물리적 도달 가능성은 단정하지 않는다.

## 재현

기존 비교용 VM에 두 workspace와 실험 헬퍼가 설치되어 있어야 한다. 두 lock이 해제된 뒤 localhost ROS domain 174에서 순차 구동한다. 다른 작업과 결과 폴더를 공유하지 않는다.

```bash
bash run.sh "$HOME/global-face-six-$(date +%s)"
```

`fixtures.py`가 여섯 월드를 한 번만 생성한다. `coverage_observer.py`는 계획기에 입력하지 않는 촬영·액션 증거를 수집하고 `coverage_metrics.py`는 각 주행을 같은 식으로 평가한다. `protocol.json`의 월드 지문이 변경되면 실행을 중단한다. `results.json`에는 완료된 회차별 수치가 기록된다. 같은 정답 배치를 이용한 파라미터 재조정은 이 비교에 포함하지 않는다.
