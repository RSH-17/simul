# 상자 완료와 미방문 구역 전환의 동일 5맵 비교

원본 v1.5.1-balanced와 별도 object-survey 후보를 비교한다. 시드 112601~112605의 기존 대형 트랙, 상자 총 5개, 벽 마커 1개와 상자 마커 2개, 원래 출발 자세와 600초 제한을 사용한다. 카메라는 480×480 5FPS다.

월드 파일 SHA256과 독립 실제 출발 위치 5cm 이내 일치를 확인한다. 시험 중 동결 정책을 변경하지 않는다. 실패 회차도 집계에 포함한다. 앞선 wall-balance 비교가 두 공통 lock을 해제한 후 localhost domain174에서 순차 구동한다.

마커 등록률과 등록 후 1.5m 실제 접근·근거리 RGB 증거를 분리한다. 엄격 완주는 세 ID, 각 마커의 근거리 증명과 독립 접근, 지도 오차 25cm 이내, 범퍼 0회를 요구한다. 평균 시간에는 미완주 600초도 포함한다. 객체별 완료·보류 원인은 object_survey.jsonl에 남긴다.

실제 벽·상자 마커 발견률과 시간 변화는 다섯 회차가 모두 끝난 뒤 비교한다. 단일 개발 맵 집합의 결과이므로 새로운 배치의 성능은 별도 실험이 필요하다.

bash run.sh ~/v151-track-five-boxes5-1795247134501974510
