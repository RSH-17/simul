팀원들, 지금까지 진행 상황 공유할게.

현재 기준판은 Mixed v1.5.1-balanced이고, 벽과 상자에 붙은 마커를 제한 시간 10분 안에 찾아 각각 실제 1.5m 안으로 접근하는 게 목표야. 대형 트랙에 상자 5개를 둔 같은 다섯 맵에서 기준판은 완주 3/5, 벽 접근 3/5, 상자 접근 9/10이었어.

최근 만든 rescue360은 6분 뒤 카메라로 아직 안 본 표면과 미지 공간 정보량을 함께 보고 이동한 다음 360도 관찰해. 같은 다섯 맵 결과는 완주 3/5, 벽 접근 3/5, 상자 접근 10/10이야. 평균 시간은 489.6초에서 458.0초로 줄었지만 벽 성공률은 같아서 아직 기준판을 교체하지 않았어. 두 버전 모두 범퍼 접촉은 없었고 실물 성능은 별도 확인이 필요해.

지금은 yeonslay 저장소의 최신 R32와도 같은 조건에서 비교 중이야. 우리 정책이 더 낫다는 전제 없이 결과를 볼 생각이야.

다들 아래 README 보고 대시보드와 완료 영상을 보면서 최적의 정책을 같이 찾아줬으면 해. 특히 안 본 벽을 건너뛰는 경우, 상자를 다 보고도 맴도는 경우, 멀리 보인 마커를 놓치는 경우를 맡아서 확인해줘. 재현 가능한 로그·영상 시각과 가설을 남기고, 기존판은 보존한 채 개인 브랜치에서 수정한 뒤 같은 맵으로 비교해주면 돼. 실패한 결과도 같이 남겨줘.
