## 개발과 최종 판정

개발에 사용한 같은 시험장 5개 배치(112601~112605)에서 원래 balanced와 후보를 비교한다. 벽과 상자의 등록·등록 후 실제 접근·엄격 완주를 각각 유지하고, 접근 또는 엄격 완주에서 개선이 있는 후보를 다음 단계에서 평가한다. 범퍼 접촉이나 오등록이 있는 후보는 선별 대상에서 빠진다. R2는 첫 두 대형 배치의 결과로 이미 상자 접근이 기준판에 미달한다. R3는 상자 도착 후 다른 면을 짧게 이어 보는 기능을, R4는 여기에 반복 판독된 작은 인쇄물 방향을 다시 보는 기능을 추가했다. 개발에 쓴 소형 칸막이·벽감에서의 성적은 시험장 후보 선택 점수에 들어가지 않는다. [상자 관찰의 반례](../2026-11-22_v151_adaptive_survey/BENCHMARK.md) · [원시 궤적 재채점](../2026-11-22_v151_adaptive_survey/development/SCREEN_AUDIT.md)

* **사진 원본**에서는 동일 월드와 출발 자세로 balanced와 동결 후보를 다시 실행한다. 선별을 통과한 후보가 없을 때도 R4와 balanced를 두 쌍 실행해 이 배치에서 실제로 어디까지 갔는지 기록한다. 이 경우 후보 채택 판정은 보류한다.
* **선별을 통과한 후보**의 전체 시험은 다섯 배치에서 아홉 쌍이다. 사진 원본을 세 쌍, 같은 시험장에 상자를 다섯 개씩 다시 배치한 네 맵을 각 한 쌍, 그중 사전에 정한 두 맵을 각 한 쌍 더 실행한다. 각 쌍은 같은 SDF·바닥·출발 자세·480×480 RGB 5FPS·600초 제한을 공유한다. 역할별 선행 순서를 바꿔 실행한다. 무작위 배치 네 개는 시험 정책을 동결한 뒤 한 번 등록하며 결과에 따라 교체하지 않는다.
* **회차 성공**은 정확한 세 ID, 각 ID 등록 후 실제 위치에서 1.5m 이내 접근, 근거리 RGB 증거, 최초 정렬 기준 저장 지도 오차 각 25cm 이내, 범퍼와 오등록 0회, 600초 이내를 모두 요구한다. 시각이 등록보다 앞선 위치는 접근 근거에서 제외한다. 출발 불일치나 기록 누락은 인프라 문제로 표시한다. 정상 기록이 있는 시간 초과·미탐은 실패로 집계한다.
* 전체 시험의 후보가 9회 모두 통과했을 때만 이 시험 묶음에서 목표를 달성했다고 말한다. 사진 원본과 개발에 쓰지 않은 네 배치의 성적을 따로 표시한다. 반복 회차를 독립 배치 수에 더하지 않는다. 단일 시험장으로 다른 방 구조나 실물의 성공률을 추정할 수 없다.
