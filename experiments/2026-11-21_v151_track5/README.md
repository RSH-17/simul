# v1.5.1 · 사진의 대형 트랙 5회

사용자가 지정한 트랙·책상 환경에서 v1.5.1-balanced를 그대로 평가한다. 앞선 8×6m 방 실험과 분리한다. 원본 demo room은 20.15×11.35m, 책상 배치·기둥·남쪽 확장 공간·트랙 외관을 유지한다. 초기 seed 112501~112505로 상자·로봇 시작점·벽 마커 1개·상자 마커 2개를 무작위 배치한다. 정책은 정답 좌표를 받지 않는다.

각 회차는 최대 600초이며 세 ID 등록, 등록 후 독립 실제 거리 ≤1.5m, 원래 세 장 ≤1.3m 근거리 증거, 저장 지도 좌표 오차 ≤0.25m, 범퍼 0회를 함께 평가한다. 정책 실패는 재시도하지 않는다. 한 번에 한 Gazebo, domain174·localhost·두 공통 lock을 사용한다. 실제 로봇은 사용하지 않는다.

정책 스테이지 `flow_v151_exposure_sync_r2_ws`, 480×480·5FPS, MPPI 전진 0.25m/s·회전 0.5rad/s·inflation 0.45m를 보존한다. 기존 track recorder의 global costmap 4Hz 변경은 사용하지 않고 선정판의 1Hz를 유지한다. 실행 중 실제 파라미터 조회로 확인했다.

사진은 환경 종류의 기준이다. 사진 한 회차의 정확한 상자 좌표를 픽셀에서 추정한 복제는 아니다. 동일 트랙 구조에서 무작위 배치 5개를 사용한다. 시뮬레이터가 최종 출력한 spawn과 scene을 평가 기준으로 쓰며, layout 생성기가 충돌 회피 중 처음 제안한 좌표와는 차이가 있을 수 있다.

첫 회차는 336.4초·52.4m·범퍼0·세 마커 등록/접근/저장 지도 검사 통과. 나머지 회차는 진행 중이며 최종 완주율은 아직 확정하지 않았다. 보드의 진행 중 표시 거리와 최종 독립 실제 이동 거리는 구분한다.
