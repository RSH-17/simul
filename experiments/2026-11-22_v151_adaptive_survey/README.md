# Mixed v1.5.1-balanced 병목 진단과 Adaptive Survey 비교

기준판의 가장 큰 실패는 벽이 어디 있는지 모른다는 것이 아니었다. 실패한 두 트랙에서 안전성 필터를 통과한 벽 관찰점이 마지막 판단 때 각각 190개와 164개였지만, 벽을 목표로 고른 횟수는 두 회차 모두 0이었다. 회전 횟수를 늘려도 마커가 붙은 면의 앞쪽을 보지 못하면 읽을 수 없다. [영상과 경로를 대조한 기록](BENCHMARK.md)

## 검증 자료

- [경로 계산 검증](distance_results.json). 과거 실제 SLAM 판단 입력 12개에 동결판과 후보판을 교대로 네 번씩 실행했다. 도달 가능한 셀과 모든 셀의 경로 길이는 완전히 일치했다. Mac에서 한 번의 도달성 계산 중앙값은 187.1ms에서 12.9ms로 줄었다. 총 임무 시간은 별도 주행으로 측정한다.
- [JPEG 재생](vision_results.json). 5개 저장 로그의 1,265장을 확인했다. 112601의 벽 7번은 원래 후보 0장에서 8px·6px 연속 두 장으로 바뀌었다. 나머지 네 로그 930장에서는 작은 후보 22개에서 26개로 증가했다. 마커 투영점이 화면에서 충분히 먼 344장에서는 양쪽 모두 0개였다. 정답 영상 위치와의 일치는 ID 판독이나 실제 접근을 뜻하지 않는다.
- [가장자리 재관찰 재생](edge_watch_results.json). 개발 로그의 199.568초에 오른쪽으로 6° 요청 1회가 나왔다. 나머지 네 로그에서 표본으로 뽑은 인접 프레임 쌍 744개에서는 요청 0회였다. 실제 회전 여부는 당시 주행을 가정한 재생만으로 알 수 없다.
- Jazzy에서 새 회귀 테스트 26개를 통과했다. 기존 테스트를 같은 109개로 고정해 다시 실행하면 동결판과 수정판 모두 99개 통과, 같은 10개 실패였다. 실패한 항목에는 기존 회복 테스트의 가짜 노드에 상태 필드가 누락된 경우와 과거 벽 관찰 기준을 기대하는 경우가 있다.
- [별도 합성 영상 스트레스 검사](vision_stress.json). 4종 배경과 181개 서로 다른 사전 ID를 포함한 인접 마커 장면 192개에서 기준판과 개선판의 판독 ID가 전부 같았다. 하나만 읽힌 장면에서는 이미 추출된 이웃 테두리 39개를 모두 보존했다. 그러나 두 번째 ID가 읽히지 않은 134개 중 익명 단서도 못 얻은 장면은 78개였다. 크게 기울거나 화면 밖으로 잘린 먼 마커는 여전히 약점이다. 의도적으로 흑백 무늬를 넣은 비마커 이미지 96장에서 익명 후보 발생은 27장→29장, 오판독 ID는 양쪽 모두 0개였다. 실제 오회전 횟수는 정지 이미지로 셀 수 없다.
- [실패 장면과 새 지도 구성](BENCHMARK.md). 개발에 쓴 대형 트랙 배치 다섯 개와 별도로, 엇갈린 칸막이가 있는 지도와 안으로 들어간 벽이 있는 지도에서도 기준판과 개선판을 각각 돌린다. 기준판과 후보판이 같은 월드 파일·출발점·600초 제한을 쓰는지 확인한다.
- [정책·설치](../../policy_candidates/2026-11-22_v151_adaptive_survey/README.md). 물리 로봇에는 배포하지 않았다.

등록 수, 등록 뒤 독립 측정한 실제 1.5m 접근, 지도 오차, 범퍼, 시뮬 소요 시간을 구분한다. 상자 마커 위치로부터 1.5m 안을 지나간 것만으로는 성공 처리하지 않는다. 알려진 5개 배치의 성능과 새로운 지도 성능을 분리한다. 각 지도에는 한 쌍만 실행하므로 개별 회차는 인과 효과나 보편적인 완주 확률을 확정하지 못한다.

## 추가 후보와 검증 조건

첫 개발 트랙 112601에서는 원본이 상자 32·103을, Adaptive Survey가 벽 7·상자 103을 찾아 접근했다. 양쪽 모두 600초에 2/3으로 종료됐다. 수정판은 상자 32에서 1.20m까지 갔지만 가까이 찍힌 영상 55장 모두 인쇄된 면이 수평 시야에 들어오지 않았다. 같은 경로에서 벽을 본 횟수만으로는 성공을 설명할 수 없다. [경로와 시야 대조](BENCHMARK.md)

이에 따라 상자 근처에 도착한 뒤 짧게 다른 면도 보는 [별도 후속 후보](../../policy_candidates/2026-11-22_v151_object_followthrough/README.md)를 동결했다. 223.7초의 저장 SLAM 상태에서는 기존 후보 목록에서 다른 면의 관찰점까지 1.60m 격자 경로를 골랐다. 이 첫 추가 관찰점도 마커의 뒷면에 해당하므로 해당 마커를 실제로 읽을 수 있었다고 볼 수 없다. 이 버전의 Jazzy 회귀 검사는 32개를 통과했다. [재생 방법과 수치](development/object_arrival_results.json)

기존 5개 트랙과 새 구조 2개는 후보를 선별하는 용도다. 벽·상자 등록 및 실제 접근, 정확한 지도, 무충돌 완주를 각각 비교한다. 최종 검증에는 8780 원본 시험장을 사용한다. 사진에 나온 원본 배치와 별도로 무작위 상자 배치를 생성하며, 반복 주행과 신규 배치 성적을 구분한다. 별도로 만든 소형맵은 진단용이다. [후속 후보 중단 기준](RESCREEN.md) · [실제 시험장 검증](../2026-11-22_exam_track_validation/README.md)

두 개발 배치에서 R2는 벽 2/2에 접근했지만 상자 접근은 2/4였다. 남은 대형 배치가 모두 성공해도 상자 접근 수가 기준판 9/10에 못 미친다. 전체 주행은 끝까지 기록하고 R3를 별도로 평가한다. [같은 상자의 카메라 방향과 판독 기회](BENCHMARK.md#두-개발-배치에서-가려진-표면과-작은-인쇄물)
