# Mixed v1.5.1 동서남북 벽 관찰 균형 비교

동결 v1.5.1-balanced와 별도 wall-balance 후보를 사용자 지정 대형 트랙의 동일한 다섯 월드에서 비교한다. 각 월드는 상자 5개, 벽 마커 1개, 서로 다른 상자의 마커 2개를 포함한다. 시드 112601~112605, 원래 출발 자세, 600초 시뮬레이션 한도, 480×480 5FPS, 동일한 Nav2 안전 설정을 사용한다.

기준판은 이미 완료한 원본 주행이며 새 후보는 고정한 소스로 각 월드를 한 번씩 주행한다. 같은 월드 파일 지문과 실제 출발점 5cm 이내 일치를 검증한다. 실행 중 파라미터나 정책을 변경하지 않는다.

벽·상자 마커의 ID 등록, 근거리 RGB 확인, 등록 후 독립 실제 거리 1.5m 접근을 함께 확인한다. 엄격 완주는 세 마커의 RGB·독립 거리·지도 오차 25cm 이하·범퍼 0회를 요구한다. 시간 평균은 미완주의 600초도 포함한다. 성공 회차 시간만의 평균은 따로 표기한다.

ROS domain174와 localhost를 사용하고 앞선 비교와 충돌하지 않도록 공통 lock이 해제된 후 순차 실행한다. 고정 정책별로 실패 회차도 집계에 포함한다.

```bash
bash run.sh ~/v151-track-five-boxes5-1795247134501974510
```
