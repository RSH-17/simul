# 외곽 순회와 상자 관찰 후 복귀의 동일 5맵 비교

원본 v1.5.1-balanced와 별도 perimeter-survey 후보를 비교한다. 시드 112601~112605의 기존 대형 트랙, 상자 총 5개, 벽 마커 1개와 서로 다른 상자의 마커 2개, 원래 출발 자세와 600초 제한을 사용한다. 카메라는 480×480 5FPS다.

월드 파일 SHA256과 독립 실제 출발 위치 5cm 이내 일치를 확인한다. 실행 중 동결 소스와 설정을 변경하지 않는다. 실패 회차도 집계에 포함한다. localhost domain174에서 공통 두 lock을 사용해 순차 구동한다.

마커 등록률과 등록 후 1.5m 실제 접근·근거리 RGB 증거를 분리한다. 엄격 완주는 세 ID, 각 마커의 근거리 증명과 독립 접근, 지도 오차 25cm 이내, 범퍼 0회를 요구한다. 평균 시간에는 미완주 600초도 포함한다. 구간별 미완료 사유와 상자별 네 면 상태는 object_survey.jsonl에 기록한다.

앞선 wall-balance 후보는 3회 완료 후, object-survey 후보는 1회 완료 후 사용자의 새 설계 승인에 따라 다음 회차에서 중단했다. 각 완료 결과와 중단 기록, 소스 작업공간은 보존했다. 이 실험의 다섯 회차와 합치지 않는다.
