# 6분 후 전 방향 정보량 탐색

원본 v1.5.1-balanced와 별도 rescue360 후보의 시뮬레이션 비교를 준비했다. 기존 대형 트랙의 시드 112601~112605, 상자 5개, 벽 마커 1개와 상자 마커 2개, 출발 자세·600초 한도·480×480 5FPS를 재사용한다. 월드 지문과 실제 초기 자세를 검증하며 정답은 평가기에만 제공한다.

먼저 전환을 30초로 앞당긴 별도 통합 시험을 150초 한도로 실행한다. 이 시험은 실제 Nav2 이동과 2π 회전, 회전 피드백·촬영 증거·액션 결과 처리를 빠르게 확인하기 위한 개발 검사다. 그 기록을 기본 360초 정책의 완주율에 합산하지 않는다.

통합 시험에서 실제 카메라 증거를 포함한 360도 완료를 확인하면 원래 360초 파라미터로 새 프로세스의 동일 5맵 비교를 시작한다. 기존 외곽 순회 후보의 완료·중단 기록은 별도 보존한다.

```bash
bash pilot.sh
# 기본 360초 정책만 직접 비교할 때
bash run.sh ~/v151-track-five-boxes5-1795247134501974510
```

엄격 성공은 세 ID, 등록 후 각 마커 실제 1.5m 접근과 기존 근거리 RGB 증거, 지도 오차 25cm 이하, 범퍼 0회를 요구한다. 시간 평균에는 미완주도 포함한다. 실제 전환 시각, 정보 이득, 회전 완료 횟수는 별도로 기록한다. 성능 결론은 해당 주행 결과가 나온 뒤 작성한다.

## 실제 회전 통합 시험

전환 시각만 30초로 앞당긴 시험에서 실제 Nav2 Spin이 성공했다. 한 바퀴 요청은 임무 109.516초, 결과는 121.936초였고 회전 피드백은 6.28584rad(약 360.15°), 유효한 촬영 시각의 카메라 관찰 갱신은 62회였다. 촬영 대기 후에는 미지 공간 이득이 0이고 카메라 표면 이득이 2.4인 다음 목표가 선택됐다. [실측 증거](pilot_result.json).

이 시험은 시간 예산이 소진돼 133초에 종료됐고 세 마커 완주에는 실패했다. 그 결과를 원래 360초 전환 정책의 완주율에 합치지 않는다. 기본 파라미터 360.0초와 behavior_server의 실제 회전 상한 0.5rad/s를 조회한 후 정식 다섯 맵 비교를 시작했다.

[실제 360도 통합 시험 영상](https://github.com/peter010905/simul/releases/download/simulation-videos-2026-11/rescue360-integration-pilot1121__v15-rescue360-balanced-m112601-pilot1121.mp4). 전환을 30초로 앞당긴 개발 검사이며, 이 영상의 세 마커 완주 판정은 실패였다. 실제 한 바퀴 회전과 영상 관찰 증거는 위 기록에서 별도로 확인했다.
