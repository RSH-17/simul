# 8780 시험장 무작위 주행 비교

시험장의 바닥, 외벽, 기둥, 남쪽 벽의 들어간 부분과 Gazebo 물리는 원본 `mixed-track-uFjtqfyJ`를 사용한다. **마커 번호와 부착물이 매번 바뀐다.** 기준판은 Mixed v1.5.1-balanced이고 비교 후보는 surface-followthrough R5다. 각 배치를 두 정책에 같은 월드와 출발 자세로 제공한다. [시뮬레이션 보드](http://192.168.252.2:8780/) · [추첨 및 실행 순서](enrollment.json)

## 시험 조건

- 이동식 장애물은 배치당 0~9개다. 상자, 긴 가림판, 두 팔로 된 ㄱ자 장애물의 위치·크기·방향과 로봇의 출발 자세를 뽑는다. 책상 배치를 유지하는 3개와 책상 상판·다리까지 옮기는 2개를 번갈아 배정했다. 이는 시험의 실제 출제 분포에 관한 추정과 별개다.
- 이 비교는 저장소 과제 기준인 **마커 3개**를 사용한다. ID는 ArUco Original 0~1023에서 중복 없이 뽑는다. 각 마커는 벽·벽 기둥·벽 돌출부 또는 이동식 장애물에 독립적으로 붙는다. 한 물체에 여러 장을 붙일 수 있다. 인쇄물 크기, 높이, 면 안에서의 위치도 바뀐다.
- 물리적으로 겹친 인쇄물은 다시 배치한다. 마커마다 시선이 트이며 로봇 출발점과 여유 40cm의 격자 통로로 연결된 관찰점이 적어도 하나 필요하다. 좁은 길, 책상, 가림판은 남는다. 이 검사는 월드 생성 조건이다. Nav2 도달 여부는 실제 Gazebo 궤적으로 측정한다.
- 5개 시드를 먼저 추첨하고 첫 배치를 한 쌍 반복한다. 5개 배치의 독립 결과와 반복 결과를 따로 집계한다. 두 정책 모두 480×480 RGB, 5FPS, 시뮬레이션 600초, 같은 Nav2 안전 설정을 사용한다. 실물 명령은 발생하지 않는다.

## 채점

정확한 ID 등록, 등록 뒤 실제 1.5m 이내 궤적, 정책의 근거리 영상 확인, 각 저장 좌표의 최초 정렬 기준 25cm 이내 오차, 오등록·범퍼 접촉 0회를 확인한다. 벽과 장애물의 등록 후 접근을 따로 센다. 성공 시간은 마지막 근거리 증거 시각으로 계산하고, 평균 시간 비교에서는 실패 회차에 600초를 배정한다. 실제 종료 시각과 거리도 함께 남긴다.

출발 전에는 동일한 빈 RGB 프레임으로 두 검출기의 준비 상태를 유지한다. 출발 뒤에는 원래 노출 시각과 픽셀을 전달한다. 출발점에서 바로 보이는 마커도 이 시점부터 채점할 수 있다. 평가기는 원본 월드 좌표로 거리를 독립 측정하고, 모든 정답을 확인했더라도 로봇에 종료 신호를 보내지 않는다.

## 실행 및 기록

기존 8780 실험 VM과 시험장 원본이 준비된 환경에서 다음과 같이 실행한다. 등록 명령을 같은 경로에서 다시 실행하면 기존 추첨을 확인한다. 다른 정책·생성기로 재현하려면 새 시험 경로를 사용한다.

```bash
trial="$HOME/camera-aware-tools/experiments/2026-11-22_random_exam/run.sh"
ws="$HOME/v151_surface_followthrough1122_r5_clean_ws"
bash "$trial" prepare "$HOME/random-exam" "$ws" --label surface-followthrough-r5 --known-count 3 --tables both
bash "$trial" run "$HOME/random-exam"
bash "$trial" status "$HOME/random-exam"
```

마커 개수도 알려주지 않는 별도 시험에는 `--known-count 0`을 사용한다. 평가기가 1~5개를 뽑고 정책에는 모든 맵에 같은 값 0을 전달한다. 양쪽 정책은 동일 영상을 같은 시각부터 받을 수 있으며, 기존 balanced는 자체 구현에 따라 세 ID를 확인하면 탐색을 끝낼 수 있다.

등록 시점에는 Jazzy 정책 검사 46개, 시험장·채점 검사 5개가 통과했다. 개발용 시드 32개씩의 두 책상 조건에서 벽 0~3개와 이동식 장애물 0~9개가 실제로 생성됐다. 주행 검사에서는 네이티브 영상을 해시로 대조하고, 시작 위치나 장비 설정이 다른 경우를 별도 표시한다. [정책 구현](../../policy_candidates/2026-11-22_v151_surface_followthrough/README.md)
